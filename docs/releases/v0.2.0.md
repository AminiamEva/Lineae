# Lineae v0.2.0 — Windows x64

Lineae 0.2 正式版，包含多文件工程编辑、改进的源码工作区与公式输入，以及中文编辑和选区修复。

## 下载

- **Lineae_0.2.0_x64-setup.exe**：离线安装包，内置 WebView2，适合首次安装。
- **Lineae-portable.zip**：便携版，解压后运行；系统需已有 Microsoft Edge WebView2 Runtime。
- **SHA256SUMS.txt**：安装包与便携版的 SHA-256 校验值。

适用于 Windows 10/11 x64。构建和打包均在 GitHub Actions 执行。

## 主要更新

- **工程与多文件编辑**：新建/打开工程、文件树、重命名与移动、删除保护、草稿恢复和磁盘变更冲突检查；Document、Source、Split 模式间切换与文件会话保留。
- **连续的 input/include 视图**：显示来源文件、淡灰边界分割线、嵌套引用总览与排序；Ctrl+Alt+J 跳出子文件；末尾空白双击新增段落写回 main。引用可折叠，保留边界页占位与原页码。
- **统一页面设置**：工程内子文件沿用主文档的纸张、方向和边距；页面设置支持撤销/重做；新建模板统一为 A4、Normal 边距。
- **源码工作区**：CodeMirror 编辑、查找替换、独立字号；Split 使用只读百分比预览；改进局部源码写回与跨模式编辑历史，保留未修改内容及混合换行。
- **公式与中文输入**：优化公式前后中文输入、光标及选区动画、上下标和算符输入、矩阵、空占位符导航与公式退出后的焦点交接。Ctrl+Shift+J 的公式退出行为保留。
- **导航和设置**：大纲、引用跳转、可折叠侧栏与文献模块整合；简体中文、English、逐字转换的繁体中文；快捷键与编辑偏好可通过设置面板及 YAML 自定义。

## 签名说明

**本版沿用 v0.1.0 的未签名发行方式，安装包和应用均没有 Authenticode 代码签名。** Windows 可能显示“未知发布者”或 SmartScreen 提示。请从本仓库发行页下载，并使用 SHA256SUMS.txt 核对文件；校验值用于确认文件完整性，不代表代码签名。

## 已知限制

- 尚未集成 XeLaTeX 编译、PDF 预览和 SyncTeX。浏览器编辑画面与真实 XeLaTeX 输出完全一致仍是持续推进的目标。
- LaTeX 支持有明确范围；不能安全映射的结构需要在 Source 模式编辑，保留源码优先。
- 不提供自动更新；请下载新版本安装包或便携版。
