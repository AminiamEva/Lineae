## Desktop downloads

- **Windows x64** offers an offline installer and a portable ZIP. Windows may show a SmartScreen warning for unsigned builds.
- **macOS Apple Silicon** offers a DMG and an app ZIP. The app is ad-hoc signed. See the [macOS installation guide](../macos-distribution.md#install-and-verify-on-a-mac) for first launch.
- **Linux x86_64** offers an AppImage and a Debian package. Mark the AppImage executable and open it, or install the Debian package with your package manager.

Use the checksum file for your platform to verify the download.
