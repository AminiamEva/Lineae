# Lineae v0.2.2 — Windows x64 与 macOS Apple Silicon

Lineae 0.2.2 汇总了公式编辑、学术 LaTeX 解析、分栏同步和跨平台快捷键的更新，并首次同时提供 Windows 与 macOS 桌面安装包。

## 下载

### Windows 10/11 x64

- **Lineae_0.2.2_x64-setup.exe**：离线安装包，内置 WebView2，适合首次安装。
- **Lineae-portable.zip**：便携版，解压后运行；系统需已有 Microsoft Edge WebView2 Runtime。
- **SHA256SUMS.txt**：Windows 安装包与便携版的 SHA-256 校验值。

### macOS 13+ Apple Silicon

- **Lineae-0.2.2-aarch64.dmg**：拖入 Applications 或 `~/Applications`。
- **Lineae-0.2.2-aarch64.app.zip**：应用压缩包。
- **SHA256SUMS**：macOS 文件的 SHA-256 校验值。

## 主要更新

- **公式编辑**：改进矩阵输入、运算符空体、上下标、括号配对、定界符和显示公式切换；修复多行公式、绝对值与行内/行间切换后的重复定界符问题。
- **公式浮动工具栏**：字体切换不再叠加嵌套命令；矩阵中同时选中多个单元格时可正确设置颜色。
- **学术 LaTeX 解析**：扩展 TeX 兼容夹具和环境覆盖，无法安全映射的结构继续以源码优先方式保留。
- **快捷键**：新增 Windows/macOS 快捷键规划表，补齐文档、工程、视图、表格、源码和公式操作；内建操作可通过 YAML 重映射或禁用。macOS 使用 Command，Windows 默认对应 Ctrl。
- **分栏与撤销**：源码和正文分栏共享选区与滚动，修复切换视图后的撤销、焦点和大纲跳转。
- **段落与页面**：继续完善 XeLaTeX 段落断行、附录编号和页面布局回归。
- **桌面端**：新增 macOS Apple Silicon 构建与 DMG 打包；Windows 继续提供离线安装包和便携版。

## 签名说明

**Windows 安装包与应用没有 Authenticode 代码签名**，Windows 可能显示“未知发布者”或 SmartScreen 提示。**macOS 应用使用 ad-hoc 签名且未经过公证**。首次打开若被系统阻止，请仅在信任下载来源时使用“系统设置 → 隐私与安全性 → 仍要打开”。

请从本仓库发行页下载，并使用对应平台的 SHA-256 校验文件核对完整性。校验值用于确认文件完整，不代表代码签名。

## 已知限制

- 尚未集成 XeLaTeX 编译、PDF 预览和 SyncTeX。
- LaTeX 支持有明确范围；不能安全映射的结构需要在 Source 模式编辑，保留源码优先。
- 不提供自动更新；请下载新版本安装包或应用包。
- 桌面构建由 GitHub Actions 在 Windows 和 macOS 上完成。
