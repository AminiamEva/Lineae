# 工程文件分割线与统一页面

1. 文件交界显示淡灰分割线，移除继续按钮。文件来源标签与结构标记继续分列避让；分割线与标签均不占正文排版空间，也不进入打印。
2. Ctrl+Alt+J 跳出当前子文件，嵌套引用回到父文件；主文件中不产生内容修改。保留 Ctrl+Shift+J 的原有环境/公式退出行为。方向键越过交界和点击线后空白时，光标进入对应父文件。快捷键在 YAML 中可自定义。
3. 页面末尾空白双击的新增段落归 main，包括从独立打开的子文件双击末尾时，先回到主文件再追加。新增段落保留源归属，避免在 projectRegion 外插入无归属节点。
4. 工程文档视图统一使用主文件的纸张、方向和边距；子文件自身源码不被重写。共享页面设置修改写回主文件，支持撤销/重做；撤销时保留后来新增的主文件正文，保存子文件时也保存相关主文件布局修改。Split 预览仍只读。
