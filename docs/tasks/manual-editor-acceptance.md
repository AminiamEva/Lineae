# 人工编辑器验收脚本

- 目的：为正文选择、列表退出、表格导航、矩阵编辑、公式边界、源码切换、保存写操作提供可重复的人工验收步骤。
- 状态：**所有步骤当前均为“未执行”**。未实际执行并记录观察结果的步骤不得标记“通过”。
- 环境：Chromium/Edge（支持 File System Access API）、HTTPS 或 `http://127.0.0.1`；MathLive 0.108；测试文档使用 `tests/fixtures/tex-compat/` 中的 1–20 号样例。
- 记录字段：日期、浏览器版本、系统、主题（浅/深）、缩放（50%/100%/300%）、输入法（中文 IME 开/关）、执行人。
- 结果代码：`未执行` / `通过` / `失败（现象+截图+控制台错误）` / `阻塞（原因）`。
- 已知实现差距（验收时按“观察并记录”，不要误判为通过）：
  - `\mathbf{\placeholder{}}` 在 MathLive 0.108 中不能被单独聚焦；当前字体/文本命令采用哨兵 `x`（如 `\mathbf{x}`）。
  - 空格键的“命令内跳出/命令外插入 `\space`”行为未稳定交付；`\space` 可通过 `\` 命令菜单输入。
  - 实时渲染是 MathLive/DOM，不与 XeLaTeX 逐像素一致；本篇只验收编辑与源码行为，不把渲染差异当失败（除非出现结构错误/丢源码）。

## 9. 结论填写规则

- 任何一步只有实际执行并记录“观察点”后才能写“通过”。
- 失败必须记录：步骤 ID、实际现象、截图/录屏、控制台错误、浏览器/缩放/主题/IME。
- 已知差距（MathLive 占位/空格、XeLaTeX 渲染差异）按“观察并记录”处理；不要把已知限制当作新回归，也不要把未完成说成通过。
- 本脚本不修改任何源码；执行结果由负责人审核后再决定是否修复/接入。
