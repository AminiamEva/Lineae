# 协作者任务清单

目标：接近 Mogan 的数学编辑和 Pages 的基础文档体验。
负责人保留公式光标、选区、矩阵、撤销、文档模型、解析、序列化和包依赖的修改权。
以下任务可独立领取；提交前必须说明修改文件和验证结果，不自行部署。

## A. 双语文案盘点（仅资料）
- 新增 docs/tasks/ui-copy-audit.md。
- 逐项列出现有按钮、菜单、提示、对话框的文件位置、当前文字、建议中英文。
- 包括空状态、错误状态、禁用原因；不修改应用源码。
- 验收：每条有真实位置，没有把 LaTeX 命令名翻译为其他命令。

## B. 图标规格（仅资料）
- 新增 docs/tasks/icon-audit.md。
- 列出缺图标的操作，建议复用的现有图标或新 SVG 名称、双语 tooltip、可访问名称。
- 不增加依赖，不改 CSS、工具栏或核心逻辑。
- 验收：图标能表达动作，保留必要文字，不能全用通用数学图标代替。

## C. 命令覆盖核对（仅资料）
- 新增 docs/tasks/command-support-audit.md。
- 核对现有命令目录中每个命令的标准拼写、参数、包依赖、权威出处。
- 分清目录存在、可解析、可渲染、可编辑四种状态；未实测写未知。
- 不手动生成大量新命令，不修改解析器或包管理器。

## D. 人工验收脚本（仅资料）
- 新增 docs/tasks/manual-editor-acceptance.md。
- 为正文选择、列表退出、表格导航、矩阵编辑、公式边界、源码切换、保存写操作步骤和预期。
- 每项包含输入、具体按键、观察点；加入中文输入法、50%/300%缩放、深浅主题。
- 未执行的步骤不能标记通过。

## 核心问题处理顺序（负责人）
1. 矩阵操作按光标所在结构定位，禁止用首个正则匹配修改多个/嵌套矩阵。
2. 公式输入按结构编辑，移除默认哨兵文字，验证占位选择和命令保留。
3. 统一公式与正文的选区、撤销边界、复制粘贴。
4. 源码保真与不支持结构的安全往返；再扩展宏、包和渲染覆盖。
