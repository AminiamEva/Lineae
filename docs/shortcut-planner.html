LINEAE / SHORTCUT WORKSHEET

先决定操作，再决定按键。

Windows 与 macOS 各填一份，分别导出 JSON 发回来。可以选择不绑定，也可以先留作待决定。这是一张离线需求表，不会执行编辑命令，也不会改变 Lineae 的实际配置。

怎么填写 · 功能核对范围 · 快捷键语法
  • 每项可选「待决定 / 沿用现状 / 不绑定 / 自定义」；两平台的选择、按键和备注彼此独立。未决定不会被当作“不绑定”。
  • 自定义按键可手填或录制：ctrl+shift+m；两段连按：ctrl+k ctrl+m；多个备选快捷键每行一个。Mac 可写 cmd、option，会规范为 meta、alt。
  • mod 仅在运行时按平台变为 Ctrl / ⌘。当前配置明确写了 ctrl 的键，在 Mac 上仍为 Control。这里展示的是仓库默认值，不是你浏览器里可能已修改的设置。
  • 「现已支持自定义」是现有 YAML 命令；「快捷键待接入」表示功能入口已实现，但尚无配置命令；「内建按键」由 CodeMirror、MathLive 或系统处理。后两类的选择是后续实现需求，不会假装已经生效。
  • 同一作用域的重复键、单键与两段连按的前缀冲突会标红。不同作用域会按实际重叠情形提示；正文与公式可复用。系统/浏览器保留键只做提醒，网页无法保证拦截。
  • 源码区有自己的键位系统，不会因为修改正文快捷键而自动跟着改。表格里的公式使用公式作用域；普通表格单元格使用正文/表格作用域。
  • 清空自定义输入不等于“不绑定”：要取消请明确选“不绑定”。导出包含全部项目，不受当前筛选影响。

功能清单按用户可见操作粒度整理；不穷举每个 LaTeX 符号、TikZ 元件或右键菜单参数。未合并的 Jeff-Giff PR #25 不在核对范围；PDF/TeX 编译等不存在的入口未列为已完成。

有错误或未决定项也可以导出草稿，文件会带上诊断信息。带回来的 JSON 是需求清单，不是可直接导入 Lineae 的 YAML。
