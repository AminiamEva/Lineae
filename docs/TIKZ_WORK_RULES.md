# TikZ 元件逐件实现工作规则（冻结）

> 本文件由用户指示固化，每开始一个新元件前必须重读。

## 规则
1. **规格唯一来源**：`docs/TIKZ_COMPONENTS_SPEC.md`（生成后冻结，任何人不得修改）。
2. **逐件实现**：严格按 SPEC 条目顺序，一次只做一件；做完该件的目录项 + 前端后，
   **立即冻结**——不得再改动与它相关的任何代码、样式、数据。
3. 每开始新元件前，重读本文件与用户的原始指令。
4. 每件完成后必须自检：吸附判定（snap points）与 adjustment points 与 SPEC 一致，
   然后才进入下一件。
5. 通用引擎（node/path/open/rect/wire/text 基类）为所有件共享，属"已冻结"基础设施；
   单件特殊行为用该件的 def 数据表达，不改基类。
6. 全部完成后输出补丁并附自检报告。
